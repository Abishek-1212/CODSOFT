## 📌 About

This repository contains the Java Development tasks completed as part of the **CODSOFT Java Development Internship**.

The objective of this internship was to strengthen Java programming skills by building console-based applications that demonstrate object-oriented programming, problem-solving, and logical thinking.

---

## 📂 Projects Included

### 🎯 Task 1 – Number Game
A console-based guessing game where:
- Random number generation
- User input handling
- Hint system (Too High / Too Low)
- Multiple attempts
- Score calculation

---

### 🎓 Task 2 – Student Grade Calculator
A Java application that:
- Accepts marks of multiple subjects
- Calculates total marks
- Computes average percentage
- Assigns grades
- Displays student results

---

### 🏧 Task 3 – ATM Interface
A simulation of an ATM system featuring:
- Deposit money
- Withdraw money
- Check account balance
- Input validation
- Bank Account class implementation

---

### 💱 Task 4 – Currency Converter
Features include:
- Currency selection
- Amount conversion
- Exchange rate calculation
- User-friendly console interface

---

### 👨‍🎓 Task 5 – Student Management System
A CRUD-based student management application that allows:
- Add Student
- Remove Student
- Search Student
- Update Student Details
- Display All Students
- File handling (if implemented)

---
